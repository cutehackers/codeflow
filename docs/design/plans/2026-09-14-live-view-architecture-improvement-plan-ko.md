# 이전 Live View 통합 계획 대체 기록

- Plan Status: Superseded

- Superseded By: [FlowView 코드 이해 최종 스펙](../specs/2026-09-14-flowview-code-comprehension-ko.md)

사용자는 별도 Live View 대신 신규·기존 기능을 이해하는 FlowView, 명시적 재분석, 요청 시 전후 비교와 직접 연결 탐색을 선택했다. 이전 near-live·Episode·별도 화면·CAS 전면 개선 계획은 현재 구현 기준이 아니다. 상세 본문은 최종 방향으로 대체했다.

기존 공개 schema·저장 데이터·proof·보안 계약의 제거를 뜻하지 않는다. 이 파일은 이전 참조의 목적지를 설명하는 대체 기록이며 활성 parent가 아니다.
