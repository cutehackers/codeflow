# 요청 흐름 개요의 최소 구현 계획

- Created: 2026-09-29
- Status: 구현 제안 · 제품 코드 미구현
- Source: 사용자의 단순한 시스템 지향과 과도한 사전 분석을 줄이라는 수정 지시
- 관련 계약: [개요와 문장별 탐색](specs/2026-09-29-requested-flow-overview-and-statement-exploration-ko.md)

## 구현 목표

**기존 CodeReadingPath를 개요로 직접 보여 주고, 선택한 코드와 전체 상세를 왕복한다.**

원문 요청을 이해한 에이전트가 기존 분석에서 주요 지점을 고른다. CodeFlow는 이미 있는 검증·저장 경로를 사용하고, 화면은 그 결과를 보여 준다. 이번 변경은 기존 승인 계약 전체의 완료를 뜻하지 않는다.

## 사용자가 할 수 있어야 하는 일

1. 검증된 읽기 경로가 있는 View를 열면 주요 처리 지점과 확인된 연결을 먼저 읽는다.
2. 항목을 누르면 같은 분석의 정확한 문장을 기존 코드 뷰에서 읽는다.
3. 문장별 탐색으로 이동해 전체 단계와 관계를 살펴본다.
4. 개요로 돌아오면 출발 항목·펼침·스크롤을 복원한다. 비교 기준도 유지한다.

읽기 경로가 없는 View는 기존 상세 탐색을 제공한다. 개요에서도 관련 조건·미확인 경계를 남기고 상세로 연결한다. 보기 전환은 분석이나 저장을 실행하지 않는다.

## 변경할 코드

| 위치 | 변경 |
|---|---|
| `web/flowview/src/components/RequestedFlowOverview.svelte` | 기존 읽기 지점·설명·관계를 표시하는 컴포넌트 추가 |
| `web/flowview/src/stores/flowNavigation.ts` | 선별 지점을 frame 목록으로 되돌리지 않고 직접 표시할 데이터 구성 |
| `web/flowview/src/stores/flowStore.svelte.ts` | 개요/상세 모드와 왕복 위치 보존 |
| `web/flowview/src/App.svelte`, `web/flowview/src/components/NavRail.svelte` | 모드 전환과 선택 연결 |
| 기존 FlowSequence·CodeView 컴포넌트 | 상세 탐색과 코드 표시 재사용 |

개요의 여러 지점이 같은 frame에 있어도 선택한 stepId를 정확히 연다. 연결은 기존 relations와 edgeIndexes를 사용하고 배열 순서로 추정하지 않는다. 현재 코드/처리 표시 모드와 개요/상세 탐색 모드는 구별한다.

## 범위 제한

새 분석 엔진, 새 공개 schema, 별도 저장소, 자동 묶기 엔진은 추가하지 않는다. 읽기 위치는 현재 세션에서 보존한다. 브라우저 간 영구 복원은 이번 변경에 포함하지 않는다.

일반 브라우저 분석이 에이전트 선별을 자동 실행한다고 가정하지 않는다. 첫 범위는 기존 에이전트 절차로 선별·검증·저장한 View의 읽기 경험이다.

## 바로 시작할 작업

기존 실제 분석 기반 브라우저 검사에 있는 CodeReadingPath를 입력으로 사용해 **개요 표시 → 코드 선택 → 상세 탐색 → 복귀**를 한 번에 구현한다. 이후 큰 실제 요청에 적용해 읽어 본다.

빠진 분기 전체 조사, 과거 버전 비교, 범용 묶기 규칙 설계를 착수 조건으로 두지 않는다. 실제 구현 중 요청을 잘못 설명하게 만드는 문제가 발견되면 해당 사례를 해결한다. 데이터가 없으면 기존 한계를 표시하며, 표현 확장이 필요하면 그 구체적 사례와 영향만 제시한다.

## 완료 확인

- 각 개요 항목이 정확한 코드로 연결된다. 같은 frame의 다른 문장도 구별된다.
- 분기·합류·미확인 연결을 잘못된 일렬 실행으로 표시하지 않는다.
- 상세 왕복에서 위치·선택·비교 기준을 잃지 않는다.
- 기존 View와 읽기 경로 없는 View가 계속 열린다.
- 실제 요청에서 주요 처리 설명과 코드 접근을 확인한다. 화면 구현 완료와 사용자 이해 개선의 확인은 구별한다.

구현 후 관련 단위 검사, `npm --prefix web/flowview run check`, `make test-ui`, `make test-flowview`, `make build`와 저장소 필수 명령인 `make fmt`, `make vet`, `make check-naming`, `make test`를 실행한다. 이 문서는 검사 통과나 구현 완료 기록이 아니다.
