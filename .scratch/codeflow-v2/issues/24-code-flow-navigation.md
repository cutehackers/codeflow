# 24: 코드 패널 흐름 탐색 — 마커 · 토글 · 증거 사슬

**What to build:** 같은 심볼에 앵커된 모든 단계가 번호 마커로 코드 위에 표시되고, 마커 클릭 시 해당 타임라인 단계로 이동한다 — 함수 하나가 열리면 그 파일 안의 흐름이 한눈에 보인다. 뷰 전환(함수 단위 / 단계 근거만 / 파일 전체)을 제공한다. 초점이 3줄 미만이거나 import·선언문만이면 함수 뷰를 강제한다(anti-one-line). 선택 흐름의 실제 앵커만으로 파일 간 증거 사슬 필을 구성하고, 클릭 시 해당 단계로 점프한다.

**Blocked by:** 23 (심볼 단위 코드 뷰).
