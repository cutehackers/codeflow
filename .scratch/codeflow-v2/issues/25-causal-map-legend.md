# 25: 아키텍처 인과 맵 + 범례 + 브레드크럼

**What to build:** 페이지 상단에 진입 경로 브레드크럼(실제 필드에서만 유도: 진입 심볼 → 파일 → flow id)을 두고, 서버가 기존 필드에서 층위(UI / Application / State / Data / External)를 결정적으로 유도해 인과 맵 스윔레인을 렌더링한다 — 계약 변경 없음. 빈 레인은 숨기고, 현재 단계 노드를 반전 강조하며, 노드 클릭 시 타임라인 · 상세 · 코드가 함께 이동하고 맵이 자동 중앙 정렬된다. 신뢰 범례(확인 / 혼합 / 미확정 + 변경)를 표시한다. 레거시 템플릿의 검증된 스타일을 포팅하고 흑백 모노크롬을 유지한다.

**Blocked by:** 24 (코드 패널 흐름 탐색 — 같은 페이지 파일 직렬 작업).

**Status:** ready-for-agent

- [x] 레인은 단계가 있는 층만 렌더링 (빈 레인 · 고스트 카드 없음)
- [x] 층위 유도가 결정적 (같은 입력 → 같은 층위, 단위 테스트)
- [x] 노드 클릭 → 전면 동기 이동 + 자동 중앙 정렬
- [x] 브레드크럼이 실제 데이터에서만 유도됨
- [x] 흑백 모노크롬 유지
