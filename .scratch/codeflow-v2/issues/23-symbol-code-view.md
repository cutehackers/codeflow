# 23: 심볼 단위 코드 뷰 (서버 + UI)

**What to build:** 코드 패널이 문장 한 줄이 아니라 감싸는 함수 본문 전체를 기본으로 보여주고, 해당 단계의 문장 줄을 강조한다. 소스 API는 20줄 강제 캡을 제거하고 요청 범위(기본 상한 ~160줄)와 파일 전체 모드(상한 내)를 제공한다. 패널 헤더에 파일 · 심볼 · 줄 범위를 표시하고, 심볼 범위 미확정 폴백 뷰에는 "주변 코드 · 심볼 범위 미확정" 라벨을 표시해 정직성을 유지한다.
