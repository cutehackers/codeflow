# 26: 검토면 완성 — 가로 타임라인 · 임팩트 체인 · 팩트 · 미연결 동작

**What to build:** 단계 내비게이션(현재/전체 + 이전/다음)과 가로 타임라인 스트립(선택 시 자동 중앙 정렬)을 제공한다. 코드 → 상태 → 화면 결과 임팩트 체인을 표시하고, 증명되지 않은 결과는 "직접 결과 없음"으로 정직하게 표기한다. 팩트 테이블(상태 입력 / 변화 / 근거, 이전 원인 / 다음 결과, 검증 상태)을 채운다. 미연결 동작(unknowns) 섹션을 렌더링한다. 카드마다 반복되던 신뢰 배지 노이즈를 헤더 칩 하나로 정리한다.

**Blocked by:** 25 (아키텍처 인과 맵 + 범례 + 브레드크럼 — 같은 페이지 파일 직렬 작업).
